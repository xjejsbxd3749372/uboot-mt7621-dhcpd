Parameter editor

Edit Xiaomi stock parameters and interface MAC addresses.
The current records are checked before any write.

Back up Config, Bdata and Factory first

Stock environment (Config)

4 KiB CRC32 record at 0x80000. These values control stock boot and first-boot settings.

—
FieldValue

Factory identity (Bdata)

16 KiB CRC32 record at 0xC0000. It normally contains the serial number, country, model, color and stock SSIDs.

—
FieldValue

MAC addresses (Factory)

Only the four verified MAC fields are changed. Keep them consecutive in WAN → LAN → RF1 → RF2 order; surrounding Wi-Fi calibration data is preserved byte-for-byte.

—
Important
  • Back up Config, Bdata and Factory before making changes.
  • Do not disconnect power while an erase block is being written and verified.
  • Deleting or changing boot fields may prevent Xiaomi stock firmware from starting.
  • Incorrect MAC addresses can break networking or permanently duplicate another device identity.
